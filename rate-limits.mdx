# Rate Limits

The API applies a fixed-window rate limit to each API key.

## Limits

| Limit | Value |
|-------|-------|
| Requests per minute | **100** |
| Window | Fixed (resets every 60 seconds) |
| Scope | Per API key |

Each API key has its own budget: traffic from one of your keys (or from another merchant)
never consumes another key's allowance. Requests that cannot be tied to an API key — for
example, a missing or invalid `Authorization` header — are limited per client IP address instead.

All Merchant API endpoints (`POST /api/merchant/orders`, `GET /api/merchant/orders/{id}/status`,
`GET /api/merchant/orders/balance`) share the same per-key budget, so status polling counts
towards the limit.

## Handling 429 responses

When you exceed the limit, the API returns `429 Too Many Requests` with an empty body. No
rate-limit headers are sent — wait for the current 60-second window to reset before retrying.

Back off and retry when you receive a `429`. Build the request inside the retry loop so each
attempt gets a fresh signature — a `POST` re-sent with its original signature is rejected as
`SIGNATURE_REPLAYED` (see [Replay protection](/signing#replay-protection)):

```javascript
// buildRequest() returns fresh { url, options } with a new X-C2C-Timestamp / X-C2C-Signature
async function fetchWithBackoff(buildRequest, maxRetries = 3) {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    const { url, options } = buildRequest();
    const response = await fetch(url, options);

    if (response.status !== 429) return response;

    // No Retry-After header is sent: wait out the 60-second window
    await new Promise(r => setTimeout(r, 60_000));
  }
  throw new Error('Max retries exceeded');
}
```

## Best practices

- **Poll at 5-second intervals** — avoid hammering the status endpoint
- **Batch where possible** — create orders in sequence, not bursts
- **Use idempotency keys** — safe retries without burning your rate limit on duplicates
- **Prefer webhooks over polling** — a `callbackUrl` costs no requests from your budget
